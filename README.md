# Курсограф

Лабораторная работа №4 по PSI. Нативное приложение для Android на Kotlin и Jetpack Compose.

Конвертер рассчитывает сумму в MDL, EUR, USD, RON, UAH или GBP. На отдельных экранах «Неделя» и «Месяц» видны курс выбранной пары, график, минимум, максимум, среднее, изменение и тенденция. Котировки загружаются из официального XML Национального банка Молдовы и сохраняются в памяти устройства.

## Запуск

[Инструкция для Windows](WINDOWS.md) описывает установку ПО, открытие проекта, создание эмулятора Android 16, загрузку веток на GitHub и проверку в режиме полёта. В Android Studio открой папку с `settings.gradle.kts`, выбери конфигурацию `app` и запусти её на эмуляторе.

Проект использует JDK 21 для запуска Gradle, Kotlin 2.2.21, Android Gradle Plugin 8.13.2, Gradle Wrapper 8.13 и Android SDK Platform 36. Минимальная версия Android — 8.0 (API 26).

## Unit-тесты

Открой PowerShell в корне проекта и выполни одну команду.

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

При первом запуске Gradle скачивает зависимости. Сами тесты работают с контрольными данными и используют JVM, поэтому для их запуска достаточно JDK и установленного SDK. HTML-результат находится в `app/build/reports/tests/testDebugUnitTest/index.html`.

## Код и отчёт

- `domain` хранит валюты, валидацию суммы и расчёт статистики.
- `data` отвечает за запросы к НБМ, разбор XML и кэш.
- `ui` содержит три маршрута Jetpack Compose и отрисовку графиков.
- [REPORT.md](REPORT.md) описывает выбор языка, данные и результаты работы с ИИ.
